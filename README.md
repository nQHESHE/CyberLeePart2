CyberLee – Cybersecurity Awareness Assistant

Project Description

CyberLee is a WPF desktop application developed in C#. It helps users learn about cybersecurity through a simple chatbot interface with voice responses.

Features

* Graphical user interface built using WPF.
* WAV audio greeting when the application opens.
* Text-to-speech responses.
* Cybersecurity guidance on passwords, phishing, privacy, viruses, scams, Wi-Fi and hacking.
* Random chatbot responses and conversation flow.
* Personalisation through remembering the user’s name.
* Chat clearing functionality.
* Basic sentiment detection and responses to user input.

Technologies Used

* C#
* .NET
* WPF
* Visual Studio 2022
* System.Speech
* WAV audio

How to Run

1. Open the project in Visual Studio 2022.
2. Restore any required NuGet packages.
3. Build the solution.
4. Run the application using F5.

Project Files

* MainWindow.xaml – defines the graphical interface.
* MainWindow.xaml.cs – handles interface events and voice functionality.
* Chatbot.cs – handles chatbot responses and conversation logic.
* Greeting.wav – contains the audio greeting.

Conclusion

CyberLee demonstrates basic object-oriented programming, graphical interface development, chatbot logic and speech functionality in C#.
